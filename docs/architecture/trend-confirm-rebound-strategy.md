## 1. 新しい戦略を追加する理由と背景

`CooldownReboundStrategy` のバックテスト結果は以下のように、一応プラスではあるものの、いくつかの課題が残っています。

**バックテスト結果サマリ（CooldownReboundStrategy）:**

- **初期資金:** 10000
- **最終総資産:** 10014.33179246
- **確定損益:** 14.33179246
- **利益率:** 0.00143318 (約0.14%)
- **売買回数:** 752 (買い376回, 売り376回)
- **利確回数:** 196
- **損切り回数:** 180
- **勝率:** 0.52127660
- **平均利益:** 6.10783605
- **平均損失:** -6.57113374
- **最大利益:** 21.71091874
- **最大損失:** -15.04448820
- **最大連続損切り回数:** 7
- **最大ドローダウン:** 0.02219943

### 課題

- **利益率が小さい**: 一応プラスだが、非常にわずかな利益にとどまっている。
- **平均利益より平均損失が大きい**: 「利小損大」の傾向がある。
- **損切り回数が多い**: 全体の約半数が損切りとなっている。
- **最大連続損切り回数が多い**: クールダウンを設けても、なお連続で損切りになる場面（最大7回）が存在する。
- **買いタイミングが早すぎる可能性がある**: 単発の反発K線だけでエントリーしているため、下落トレンド中の「ダマシ」の反発を拾ってしまい、すぐに損切りに引っかかっている可能性が高い。

### 解決方針

これらの課題を解決するため、反発K線だけでなく、**短期的な流れ（トレンド）が上向きに変わり始めたことを確認してから買う**戦略 `TrendConfirmReboundStrategy` を導入します。

## 2. TrendConfirmReboundStrategy の概要

`TrendConfirmReboundStrategy` は、`CooldownReboundStrategy` をベースにした新しい戦略です。

目的は、下落後の反発を狙いつつ、単発の反発サインだけでは買わず、短期的な流れが上向きに変わり始めたことを確認してから買うことです。

## 3. CooldownReboundStrategy との違い

| 項目             | CooldownReboundStrategy                      | TrendConfirmReboundStrategy        |
| ---------------- | -------------------------------------------- | ---------------------------------- |
| **目的**         | 下落後の反発を狙う                           | 下落後、短期的な上向き確認後に買う |
| **買い条件**     | 下落 + 急変動なし + 反発K線 + クールダウン外 | 既存条件 + **MA5上抜け確認**       |
| **売り条件**     | 買値基準の利確・損切り                       | 同じ                               |
| **クールダウン** | 損切り後に一定期間買わない                   | 同じ                               |
| **狙い**         | 反発初動を拾う                               | 早すぎる買いを減らす               |
| **想定効果**     | 取引機会を確保しやすい                       | 損切り回数・連続損切りの減少を狙う |

## 4. 買い条件

既存の `CooldownReboundStrategy` の買い条件に加えて、**MA5（直近5本の終値平均）の上抜け確認**を追加します。

### 追加する条件（MA5上抜け確認）

- 最新の終値が最新の MA5 より上
- 直前の終値は直前の MA5 以下
- 最新の MA5 が直前の MA5 より上

### この条件で確認すること

- 直前までは短期平均線の下にいた（下落傾向）
- 最新足で短期平均線を上抜けた（反発の勢い）
- MA5 自体も上向きになっている（短期トレンドの好転）
- **単なる一時的な反発ではなく、短期的な流れが上向きに変わり始めた可能性を見る**

## 5. 買い見送り条件

以下の場合は買わない方針とします。

- 必要なK線本数が足りない（MA5計算に必要）
- 急変動が発生している
- 1時間の下落条件を満たしていない
- 反発K線の条件を満たしていない
- MA5上抜け条件を満たしていない
- 損切り後のクールダウン期間中である
- すでにポジションを保有している

## 6. 売り条件

売り条件は `CooldownReboundStrategy` と同じです。今回の改善では、買い条件だけを変更します。

### 変更しないもの

- 利確条件
- 損切り条件
- `sellThreshold`
- クールダウン開始条件
- 保有中の判定

## 7. バックテストで確認する指標

実装後、以下の指標で各戦略を比較します。

- 最終総資産
- 確定損益
- 利益率
- 売買回数
- 買い回数
- 売り回数
- 最大ドローダウン
- 利確回数
- 損切り回数
- 勝率
- 平均利益
- 平均損失
- 最大利益
- 最大損失
- 最大連続損切り回数
- 未決済ポジションあり

### 比較対象

1. `SafeReboundStrategy`
2. `CooldownReboundStrategy`
3. `TrendConfirmReboundStrategy`

## 8. 評価観点

`CooldownReboundStrategy` と比べて、以下が改善しているか確認します。

- 損切り回数が減っているか
- 最大連続損切り回数が減っているか
- 平均損失が悪化していないか
- 最大ドローダウンが悪化していないか
- 利益率が改善しているか
- 売買回数が減りすぎて、機会損失が大きくなっていないか
