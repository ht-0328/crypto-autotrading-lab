## 概要

GCP（Googleのクラウド）を使うための最初の準備です。アカウントを用意し、プロジェクトという「箱」を作り、料金を払うための設定をします。

## 1. Google アカウントの準備

Google Cloud を使うには Google アカウントが必要です。

- 個人開発なら、普段の個人のアカウントで問題ありません。
- 会社で使う場合は、会社のアカウントを使ってください。

## 2. GCP プロジェクトを作成する

Google Cloud 上のシステムはすべて「プロジェクト」という単位で管理されます。

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. 画面上の「プロジェクトの選択」を開き、「新しいプロジェクト」をクリックします。
3. **プロジェクト名** を入力します。
4. **プロジェクト ID** が自動で作られます。（後から変えられないので注意してください）
5. 「作成」ボタンを押します。

!!! note "プロジェクト ID の読み替え"

    これ以降の説明では、作ったプロジェクト ID を `<YOUR_GCP_PROJECT_ID>` と読み替えてください。

## 3. 課金アカウントを設定する

GCPの様々な機能（Cloud Run など）を使うには、プロジェクトに「課金アカウント」を紐づける必要があります。

1. Cloud Console の左側メニューから「お支払い（Billing）」を選択します。
2. クレジットカード情報などを登録して課金アカウントを作成します。
3. 作った課金アカウントを、先ほど作ったプロジェクトに紐づけます。

**注意点:**
無料枠もありますが、使い方によっては料金が発生します。無駄なお金を払わないよう、不要になったものはこまめに消すことが大切です。
