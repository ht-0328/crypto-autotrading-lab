# デプロイ先比較: AWS / GCP

## 目的

* 将来の本番運用に向けて、AWS/GCP の比較軸を事前定義する。
* 実装前に評価観点を揃え、意思決定を透明化する。

## 比較対象

* AWS
* GCP

## 比較軸

### 1. 実行基盤（Batch / Container / Cron）

評価観点:

* バッチ実行のしやすさ（ジョブ定義、再実行、依存関係管理）
* コンテナ実行の運用性（イメージ管理、起動時間、スケール、ネットワーク設定）
* Cron 相当のスケジュール実行機能（時刻精度、タイムゾーン、失敗時リトライ）
* ローカル開発環境との移植性

### 2. Secret 管理

評価観点:

* Secret の保存・暗号化・アクセス制御の仕組み
* アプリへの注入方法（環境変数/マウント/実行時取得）
* ローテーション運用のしやすさ
* 監査ログやアクセス追跡の可視性

### 3. ログ / 監視

評価観点:

* アプリログの収集・検索性
* メトリクス監視とアラート設定の柔軟性
* トレースや障害調査のしやすさ
* 通知連携（メール/チャット/オンコール）

### 4. コスト上限

評価観点:

* 月次予算上限を設定しやすいか
* 予算超過時の検知・通知・抑制機能
* 小規模運用時の最低コスト
* 実行回数やログ量増加時のコスト見通し

## 意思決定ルール（案）

* 各比較軸を 5 段階でスコアリングし、理由を記録する。
* 必須条件（例: Secret 管理、監査性）を満たさない選択肢は除外する。
* 最終判断は PoC 結果と運用負荷見積もりを併記して合意する。
