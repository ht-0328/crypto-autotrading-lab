# ドキュメント (Documents)

このディレクトリには、プロジェクト全体の仕様書や設計書などのドキュメントが含まれています。

## ディレクトリ構成

- **`specifications/`**: 仕様書を置く場所です。何を満たす必要があるか、入力・出力・条件・エラー・具体例などを定義しています。仕様を確認したい場合はここを参照してください。
- **`architecture/`**: 設計書を置く場所です。どのように作るか、責務分担・処理の流れ・クラス配置・データ保存などを定義しています。設計を確認したい場合はここを参照してください。
- **`templates/`**: 仕様書および設計書を作成する際のテンプレートを置いています。新しいドキュメントを作成する場合は、これらのテンプレートを利用してください。
- `overview/`: プロジェクトの概要や目的などをまとめたドキュメント群です。
- `development/`: 開発環境の構築方法や手順などをまとめたドキュメント群です。
- `operations/`: システムの運用方法や手順などをまとめたドキュメント群です。
- `ai/`: AIエージェント向けのルールやガイドラインが置かれています。

## 主要なドキュメント

- [Phase1 シミュレーション 仕様書](specifications/phase1-simulation.md): フェーズ1の全体スコープと仕様。
- [売買戦略のロジック解説](architecture/trading-logic.md): 売買判定の基本ロジック（いつ買い、いつ売るのか）。
- [バックテスト機能 仕様書](specifications/features/backtest.md): 過去K線を使ったバックテストの仕様。
