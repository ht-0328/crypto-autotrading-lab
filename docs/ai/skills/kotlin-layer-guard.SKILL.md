# Skill: kotlin-layer-guard

## 1. 目的

Kotlinコードのレイヤ依存ルール（Domain -> Infraの依存禁止など）違反を検出し、修正方針を提示する。

## 2. 実行手順

1. レイヤと許可された依存方向を明文化する。
2. 対象コードの import、型参照、Gradle依存を点検する。
3. 違反箇所を特定し、重大度で分類する。
4. 修正案と、再発防止のための自動検査案（detekt等）を提示する。

## 3. 制約事項

- 違反を指摘するだけでなく、必ず「具体的な修正コード案」をセットで提示すること。

## 4. 出力要件

以下の項目を出力すること。

- 違反一覧（ファイルパス、行番号、違反理由）
- 修正提案（具体的なコード差分）
- 再発防止チェック案
