# Skill: trading-safety-review

## 1. 目的
自動売買ロジックを損失制御の観点でレビューし、重大リスク（意図せぬ連続発注や異常値での取引）を低減する。

## 2. 実行手順
1. 損失シナリオ（価格の急変、流動性低下、API障害、ネットワーク切断）を列挙する。
2. 既存コードのリスク制御（注文上限、SL/TP、停止条件）を確認する。
3. 「検知」「抑制」「停止」「復帰」の観点でギャップ分析を行う。
4. 優先度付き改善案と異常系テスト案を作成する。

## 3. 制約事項
- 利益を上げるロジックではなく、あくまで「損失をいかに防ぐか（フェイルセーフ）」の観点に絞ること。

## 4. 出力要件
以下の項目を出力すること。
- リスク評価サマリ
- 未対策項目（優先度付き）
- 推奨する異常系テストケース
