# AI Prompt Rules & Output Format

## 概要

本ドキュメントは、AIエージェントがユーザーからの依頼を処理する際の期待動作と出力形式を定義しています。作業完了時の報告フォーマットの基準となります。

## 適用対象

すべてのAIコーディングエージェント

## 必ず読む関連ドキュメント

[agents-guidelines.md](agents-guidelines.md)

本ドキュメントは、AIエージェントがユーザーからの依頼を処理する際の期待動作と出力形式のルールを定義する。

## 依頼解釈のルール

- **背景/目的**: ユーザーの依頼の目的を理解し、スコープ外の過剰な変更を行わないこと。
- **対象ファイル**: 明示された「変更可」「新規可」のファイルのみを操作対象とすること。
- **変更禁止領域**: 指定されたディレクトリ、ファイル、API、設定キーの互換性を厳格に維持すること。
- **受け入れ条件**: 提示されたすべてのチェックボックス（検証事項）を満たすように実装・テストを実行すること。

## AI出力フォーマットの厳守

AIは作業完了時（または回答時）に、必ず以下の項目を含めて報告すること。

- **差分サマリ**
  - どのファイルをどのように変更したかの概要を箇条書きで記載する。
- **テスト/検証結果**
  - 実行した検証コマンド（例: `./gradlew test`）とその結果（成功/失敗）を明記する。
  - 失敗した場合はその原因と対応状況を含める。
- **リスク/未対応**
  - 既知の懸念点、残存リスク、またはユーザーへのフォローアップ事項を記載する。

## 禁止事項

各ルールの詳細および `agents-guidelines.md` の絶対禁止操作を参照すること。

## 判断に迷った場合

推測で判断せず、ユーザーに確認を求めること。

## 完了報告の形式

`prompt-template.md` で定義されたフォーマットを厳守すること。
