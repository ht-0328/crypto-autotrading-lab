# AI依頼テンプレート

AIに実装/修正を依頼する際は、以下のフォーマットをそのまま使ってください。

## 1. 背景/目的
- 何を解決したいか
- なぜ今それが必要か
- 想定している利用者/運用シーン

## 2. 対象ファイル
- 変更してよいファイルを明示する
- 新規作成が必要な場合はパスを明記する

例:

```text
- 変更可: projects/crypto-autotrading-app/src/main/kotlin/.../TradingStrategy.kt
- 新規可: docs/notes/strategy-decision-log.md
```

## 3. 変更禁止領域
- 触ってはいけないディレクトリやファイル
- 既存APIや設定キーなど、互換性維持が必要な項目

例:

```text
- 変更禁止: domain/model 配下の公開データ構造
- 互換性維持: application-*.yaml の既存キー名
```

## 4. 受け入れ条件
- 期待する挙動をチェック可能な形で列挙する
- 成功/失敗条件を明確化する

例:

```text
- [ ] `./gradlew test` が通る
- [ ] 既存のCSVフォーマットを壊さない
- [ ] 例外時に原因がログで追跡できる
```

## 5. 出力形式（差分、テスト、リスク）
AIの回答は必ず以下を含める:

1. **差分サマリ**
   - どのファイルをどう変えたか
2. **テスト/検証結果**
   - 実行コマンドと結果（成功/失敗）
3. **リスク/未対応**
   - 既知の懸念点、フォローアップ項目
