# AI Skills Catalog

本ドキュメントは、プロジェクト内でAIが提供可能な特定の専門スキルとその入力・出力仕様を定義する。

## 1. spec-writer（仕様策定支援）
* **目的**: 曖昧な要件を実装・検証可能な仕様に落とし込む。
* **入力**: ユーザーからのIssueや要望文、既存の `docs/human/` 仕様書、関連コード。
* **出力**: 仕様サマリ、制約一覧、テスト可能な受け入れ条件、未確定事項のリスト。
* **ルール**: 推測で仕様を決定しないこと。不明点は必ず質問として挙げる。

## 2. kotlin-layer-guard（Kotlin依存関係監査）
* **目的**: Kotlinプロジェクトの厳格なレイヤ依存ルールを監視し、違反を検出する。
* **入力**: `projects/crypto-autotrading-app` のコード、ビルド設定。
* **出力**: 依存違反のリスト（箇所・理由）、修正コード案、再発防止策の提案。
* **ルール**: 単なる指摘に留めず、必ず具体的な修正コードの差分を提示すること。

## 3. trading-safety-review（自動売買リスク監査）
* **目的**: 取引ロジックを損失制御（フェイルセーフ）の観点でレビューする。
* **入力**: 戦略仕様、リスク設定コード。
* **出力**: リスクシナリオ別の評価、防御策の不足点の指摘、異常系テストケースの提案。
* **ルール**: 「利益を上げる」観点ではなく、異常事態（API障害、急変等）における「損失を防ぐ」観点に特化すること。
