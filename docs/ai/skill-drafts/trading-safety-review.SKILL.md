# Skill: trading-safety-review

## Purpose
自動売買ロジックを損失制御の観点でレビューし、重大リスクを低減する。

## When to use
- 新戦略導入前
- リスク設定変更時
- インシデント後の再発防止レビュー時

## Inputs
- 戦略仕様
- リスク制御パラメータ
- 実装・テストコード

## Workflow
1. 損失シナリオ（急変、流動性低下、API障害）を列挙。
2. 既存制御（注文上限、SL/TP、停止条件）を確認。
3. 検知・抑制・停止・復帰の観点でギャップ分析。
4. 優先度付き改善案と異常系テスト案を作成。

## Output
- リスク評価サマリ
- 未対策項目（優先度付き）
- 推奨テストケース

## Done criteria
- 重大損失につながる未対策リスクへの具体策が提示されている。
