# PRとコミットの作成ルール

## 1. コミットメッセージ作成手順

- コミットメッセージは日本語で書くこと。
- `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:` などの接頭辞は使ってよい。
- ただし、接頭辞の後ろは必ず日本語にすること。
- 英語だけのコミットメッセージは禁止すること。
- 内容が曖昧なコミットメッセージは禁止すること。
- コミット作成前に、メッセージが日本語になっているか確認すること。

**良い例**:
- `docs: PRとコミットの作成ルールを追加`
- `fix: PR本文作成ルールの矛盾を修正`
- `chore: AIエージェント向けの作業ルールを整理`

**悪い例**:
- `Update files`
- `Fix bug`
- `Changes`
- `Improve docs`

## 2. PRタイトル作成手順

- PRタイトルは日本語で書くこと。
- `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:` などの接頭辞は使ってよい。
- ただし、接頭辞の後ろは必ず日本語にすること。
- 英語だけのPRタイトルは禁止すること。
- 内容が曖昧なPRタイトルは禁止すること。
- PR作成前に、タイトルが日本語になっているか確認すること。

**良い例**:
- `docs: PRとコミットの作成ルールを追加`
- `fix: PR本文作成ルールの矛盾を修正`
- `chore: AIエージェント向けの作業ルールを整理`

**悪い例**:
- `Update AGENTS`
- `Fix`
- `Add changes`
- `Improve docs`

## 3. PR本文作成手順

PR本文を作成する場合、AIエージェントは必ず次の順番で作業すること。

1. `.github/pull_request_template.md` を読み直す
2. テンプレートの見出しをそのまま使う
3. テンプレートの順番をそのまま使う
4. テンプレートのチェックボックスをそのまま使う
5. 各項目に日本語で内容を書く
6. 該当しない項目には `該当なし` と書く
7. 実行していない確認やテストを、実行済みのように書かない
8. PR作成前に、テンプレートとPR本文を照合する

**禁止事項**:
- PRテンプレートの見出しを削除すること
- PRテンプレートの見出しを並べ替えること
- PRテンプレートにない独自見出しを追加すること
- チェックボックスを削除すること
- 空欄を残すこと
- チャット報告用の項目をPR本文に入れること
- `AI確認済みドキュメント` をPR本文に追加すること
- `備考`、`検証結果`、`リスク / 懸念点` など、テンプレートにない見出しを追加すること

## 4. PR本文の自己チェック手順

PR作成前に、以下の項目を必ず確認し、失敗した場合はPRを作成せず、本文を修正してから作成すること。

- [ ] `.github/pull_request_template.md` の見出しがすべて残っているか
- [ ] 見出しの順番が変わっていないか
- [ ] チェックボックスが削除されていないか
- [ ] テンプレートにない独自見出しを追加していないか
- [ ] 空欄が残っていないか
- [ ] 該当しない項目に `該当なし` と書いているか
- [ ] PRタイトルが日本語になっているか
- [ ] PR本文が日本語になっているか
- [ ] 実行していない確認を実行済みとして書いていないか

## 5. チャット報告とPR本文を分けるルール

- チャットでの作業完了報告とPR本文は別物として扱うこと。
- チャット報告用の項目をPR本文に混ぜないこと。
- `AI確認済みドキュメント` は、必要な場合でもチャット報告にだけ書くこと。
- PR本文の形式は `.github/pull_request_template.md` だけを正とすること。

## 6. 違反時の修正手順

- コミットメッセージが英語だけの場合は、日本語に修正すること。
- PRタイトルが英語だけの場合は、日本語に修正すること。
- PR本文が `.github/pull_request_template.md` に沿っていない場合は、PR作成前に修正すること。
- PR本文にテンプレート外の独自見出しを入れてしまった場合は、削除すること。
- PR本文に空欄がある場合は、具体的な内容または `該当なし` を記入すること。
- ユーザーから「テンプレ通りではない」「日本語になっていない」と指摘された場合は、該当箇所を修正すること。
