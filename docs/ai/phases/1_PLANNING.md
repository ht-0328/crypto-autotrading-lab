# Phase 1: 計画と調査 (Planning)

このフェーズの目的は、タスクの要件を正確に理解し、変更すべきファイルを特定することです。
内部知識（学習データ）は不正確な場合があるため、推測で作業せず、必ずツールを用いてリポジトリの最新情報を取得してください。

## アクションガイド
1. ユーザーの依頼内容を読み、関連する仕様書や対象のソースコードをツールで読み込んでください。
2. Kotlinコードを変更する場合は、事前にアーキテクチャの境界ルールを把握するため `docs/ai/kotlin-boundary-rules.md` を読み込んでください。
3. 必要に応じて `docs/ai/skills-catalog.md` を読み込み、今回のタスクに役立つスキルファイル（.SKILL.md）を追加で取得してください。
4. 調査が完了し、どのファイルのどこを修正すべきか計画が完了したら、AGENTS.md の指示に従い **Phase 2 (`docs/ai/phases/2_CODING.md`)** を読み込んで次のステップに進んでください。
