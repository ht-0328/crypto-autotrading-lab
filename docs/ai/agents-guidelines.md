# AGENTS.md 標準ガイドライン

この文書は、プロジェクトで運用する `AGENTS.md` に記載すべき標準項目を定義します。

## 1. スコープ

- `AGENTS.md` が適用されるディレクトリ範囲を明示する。
- 例:
  - 「このファイルは `projects/crypto-autotrading-app/` 配下に適用」
  - 「下位ディレクトリに別 `AGENTS.md` がある場合はそちらを優先」
- 対象外（非スコープ）も明記する。

## 2. 禁止操作

- 安全性・品質・機密保持のための禁止事項を列挙する。
- 例:
  - 本番環境への直接デプロイ
  - 秘密情報（APIキー、秘密鍵）の生成・出力・コミット
  - 破壊的DB操作（`DROP`, `TRUNCATE` など）
  - 無断での依存ライブラリ大規模更新
- 禁止理由（セキュリティ / コンプライアンス / 運用事故防止）を短く添える。

## 3. 必須チェック

- 変更前後で必ず実施するチェックを明記する。
- 推奨構成:
  - **静的解析**: lint, format, detekt, ktlint
  - **テスト**: unit / integration / e2e の最低ライン
  - **ビルド**: 対象モジュールのビルド成功
  - **設計ルール**: レイヤ依存、命名規則、公開API互換性
- 失敗時の扱い（修正優先 / エスカレーション条件）を明記する。

## 4. 出力フォーマット

- AIエージェントの最終報告の形式を統一する。
- 最低限含める項目:
  1. 変更概要（ファイル別）
  2. 実行コマンドと結果（成功/失敗）
  3. 未解決事項・リスク
  4. 次アクション提案
- PR説明文テンプレート（目的、変更点、テスト結果、懸念点）を定義する。

## 推奨テンプレート（ひな形）

```md
# AGENTS.md

## Scope
- この指示の適用範囲: <path>
- 非適用範囲: <path>

## Prohibited Operations
- <禁止操作1>
- <禁止操作2>

## Required Checks
- <check command 1>
- <check command 2>

## Output Format
- Summary:
- Testing:
- Risks:
- Next Actions:
```
